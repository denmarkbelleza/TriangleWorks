# Triangle Works: Bike Frame Studio

**Student:** BELLEZA, DENMARK JAY D.

**Category:** E-Commerce

## Description
Triangle Works is an online shop for carbon road bike frames. Visitors can browse frames, find their size, pick a size, add frames to a cart and send inquiries.

## Main Features
- Shop with live search, filters (type, material, size) and price sorting
- Size picker on every frame that must be chosen before adding to the cart
- Fit calculator that recommends a frame size from inseam and riding style
- Shopping cart saved in Local Storage (add, remove, change quantity, total)
- Contact form with validation
- Frame data loaded from `frames.json` using the Fetch API
- Responsive layout for phone, tablet and desktop

## Technologies Used
HTML5, CSS3, JavaScript (Fetch API, Local Storage), Google Fonts

## How to Run
Open the folder in VS Code and run with Live Server (needed so `fetch` can load `frames.json`), or publish with GitHub Pages.

Live site: https://denmarkbelleza.github.io/TriangleWorks/
